3) ตัวอักษรพิเศษ
   - เก็บไว้ตามเดิม (ห้ามแปลง): กรีก λ α θ Ω Ω(=U+2126) Φ µ และ
     ≤ ≥ ∫ ∑ ∑∑ ∆ ½ –(en-dash) และปี/เลขในข้อความ
   - จุดคูณ ⋅/· ทุกตัว -> *
   - ราก √(...) -> sqrt(...)
   - ตัวห้อยยกขึ้น inline: αeff->α_eff, αmin->α_min, αmax->α_max, S_UV(λ) เป็นต้น

4) หน่วย (convention: ใช้ ^ แทนตัวยก)
   - W⋅m-2·sr-1·nm-1 -> W/(m^2*sr*nm)
   - W⋅m-2⋅sr-1      -> W/(m^2*sr)
   - W⋅m-2           -> W/m^2
   - J⋅m-2           -> J/m^2
   - cd⋅m-2          -> cd/m^2
   - nm-1 (ที่แปลว่า per nm) -> nm^-1 เช่น "[X]*nm^-1", "W/(m^2*sr) nm^-1"
   - เลขยกกำลังที่กำกวมจาก PDF ถูก disambiguate:
       104 s -> 10^4 s, 106 nm -> 10^6 nm, 106/t -> 10^6/t
       10-4 -> 10^-4,  (7/3)2 -> (7/3)^2,  t^0.25 เป็นต้น
   - ทศนิยมจุลภาค digit,digit -> digit.digit (เช่น 0,011 -> 0.011)
     (คอมมาที่ไม่ใช่เลขเลข — ปีบรรณานุกรม "1980," — คงไว้)

5) สมการ (ยกกำลัง / differential / integral)
   - สูตรที่ PDF แยกตัวอักษรต่อบรรทัด ถูกยุบเป็น 1 บรรทัด ASCII
   - คูณ = *  (ไม่มี ⋅/·), หาร = /, ยกกำลัง = ^, ตัวห้อย = _
   - differential: เขียน dA, dΦ, d(λ) (ตัว d หน้าปริมาณ)
   - integral: ∫  คงไว้ ; summation: ∑ (ชั้นเดียว) / ∑∑ (สองชั้น)
   - ตัวอย่าง:
     E_v = dΦ_v / dA
     H = ∫ E * d(∆t)
     Q = ∫ Φ * dt
     L_λ = dΦ(λ) / (cosθ * dA * dΩ * dλ)
     ΣΣ E_λ(λ,t) * B(λ) * ∆λ * ∆t ≤ 100 J/m^2
     t_max = 10^6 / L_B  [s]
     Σ L_λ(λ) * R(λ) * ∆λ ≤ 50000 / (α * t^0.25) W/(m^2*sr)
